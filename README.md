## G2P-SEED-a-new-AI-approach-for-genomic-prediction-and-interpretation-in-plants
Source code for my MSc thesis on genomic prediction in apple, including phenotype and genotype preprocessing, multimodal neural networks, SHAP-based model interpretation, and Genetic Algorithm-based SNP feature selection for Harvest date, Acidity, and Color over.

## Dataset & Data Availability

Due to GitHub file size constraints, some of the datasets used in this project are hosted externally on Zenodo. 
The available files comes from the study of Jung et al. (2025) and public repository.

# Download Dataset (Zenodo): https://doi.org/10.5281/zenodo.22116523
